## Executive Overview

On October 21, 2026, the SGX3 Fall Training 2026 program convened its second virtual session, accelerating undergraduate participants along a rigorous, workforce-aligned trajectory toward High-Performance Computing (HPC), Research Computing and Data (RCD), Artificial Intelligence (AI), Super Intelligence (SI), and Science Gateways proficiency. Session 2 was co-led by workforce development leads Jeaime Powell and Dr. Linda Hayden, alongside senior student assistant Kimora Mason.

The Fall 2026 cohort comprises a select group of 12 accepted students—including 11 undergraduate trainees representing regional institutions such as Elizabeth City State University (ECSU) and Norfolk State University (NSU), supported by 1 senior student assistant. Designed to bridge academic computer science curricula with national cyberinfrastructure environments, the session focused on three core operational pillars:

1. **Navigating the Dual-Track 2026 Fall Training Task Sheet Roadmap:** Clarifying specific operational milestones, deliverable upload protocols, and grading deadlines required for participants to earn the program's $500 stipend.
2. **Operationalizing Veteran Student Peer Leadership:** Transitioning returning cohort members from learners to session leads who facilitate technical modules, present webinar analyses, and mentor first-time trainees.
3. **AI-Accelerated Portfolio Engineering & Workflow Continuity:** Demonstrating advanced software engineering workflows that leverage modern Large Language Models (LLMs), document ingestion, and GitHub Pages for rapid web development, while addressing critical cyberinfrastructure and environmental sustainability considerations.

This workforce development initiative is supported by federal cyberinfrastructure grants. The Science Gateways Community Institute (SGCI) is funded by the National Science Foundation (NSF) under Award #ACI-1547611, and SGX3 is funded by the NSF under Award #2231406.

## Dual-Track 2026 Fall Training Task Sheet Roadmap & Program Expectations

The SGX3 Fall Training Task Sheet serves as the foundational curriculum roadmap. To accommodate varying levels of experience, the Fall 2026 program implements a dual-track structure distinguishing first-time trainees from returning veteran participants.

### Program Mandates & Deadlines

- **Total Effort:** All participants are expected to commit approximately 40 hours of total effort across the training window (October 19 – December 30, 2026).
- **Deliverable Submission Repository:** Certificates, written reviews, code artifacts, and verification screenshots must be organized and uploaded directly to each student's assigned folder within the official Student Deliverables Google Drive Repository.
- **Stipend Eligibility Deadline:** To guarantee receipt of the $500 participant stipend, all required task sheet items must be completed, uploaded, and fully graded on or before Wednesday, December 30, 2026.

| First-Time Trainee Track | Returning Veteran Lead Track |
|---|---|
| Complete core technical modules | Lead cohort sessions on core modules |
| Complete external certifications | Facilitate peer technical reviews |
| Write 2-page webinar reviews | Present past reviews & lead debates |
| Establish professional online identity | Expand & update GitHub/Slack/LinkedIn |

### Track 1: First-Time Trainee Curriculum

First-time participants focus on building foundational technical competencies across command-line tools, software development frameworks, and scientific computing platforms:

- **Vim Essentials (Amigoscode):** Mastery of modal command-line text editing, key bindings, buffer management, and shell navigation.
- **Introduction to Git (DataCamp GitHub Foundations Track - 2 hrs):** Core version control mechanics, commit histories, branching strategies, and repository management.
- **Kaggle Python Certification (5 hrs):** Fundamental Python scripting, control structures, data handling, and algorithmic logic for data science.
- **Bandit Linux Challenge & Command Cheat Sheet:** Practical Linux shell navigation, file system permissions, and command-line security exercises.
- **Spring Boot for Beginners (Amigoscode):** Introduction to enterprise Java application frameworks and backend architectural design.
- **Kaggle Intro to Machine Learning Certification (3 hrs):** Foundational supervised learning concepts, decision trees, model validation, and scoring metrics.
- **Google Cloud Computing Foundations: Cloud Computing Fundamentals (Skills Boost - 8 hrs):** Cloud infrastructure primitives, virtual machines, object storage, and resource management.
- **Science Gateways Webinar Reviews:** Watch two designated community webinars (including *Resource Providers of Science Gateways* and a selection from the official Science Gateways Webinar Archive), draft a comprehensive 2-page summary for each featuring critical analysis, quotes, and research questions, and subscribe to the SGX3 Newsletter.

### Track 2: Returning Veteran Lead Track

Returning participants transition from technical instruction to peer leadership, communication, and community engagement:

- **Cohort Session Facilitation:** Lead instructional walkthroughs and Q&A sessions for the core technical tracks (Vim, Git, Kaggle Python, Bandit Linux, Spring Boot, Kaggle ML, and GCP).
- **Webinar Presentation & Discussion Leadership:** Present previously authored 2-page webinar reviews to the cohort, select an additional archive webinar, and lead structured peer discussions on gateway architectures and research computing infrastructure.
- **Digital Identity Refinement:** Update existing Slack profiles, refresh LinkedIn credentials, and enhance existing GitHub Pages portfolios with modern project work, personal statements, and professional links.

### Professional Identity & Career Readiness (Both Tracks)

To prepare participants for national research computing opportunities, all students must complete four core career readiness milestones:

1. **Slack Workspace Integration:** Configure a complete profile featuring a professional headshot and post a 2–3 paragraph introductory biography in the cohort workspace.
2. **LinkedIn Professional Networking:** Establish or update a detailed LinkedIn profile and link directly to the official Science Gateways Community Institute / SGX3 Page.
3. **GitHub Pages Web Portfolio:** Initialize a public GitHub repository, enable GitHub Pages, and publish a responsive developer site containing a resume, professional headshot, personal statement, and links to professional profiles (LinkedIn, GitHub, ORCID).
4. **National Program Applications:** Apply to at least two (2) summer research internships or national scientific computing conference student programs (e.g., PEARC27, SC27, USRSE, or the Oak Ridge National Laboratory PCIP internship).

### National Cyberinfrastructure Platforms & Reflection Requirement

Participants must create or verify active user accounts on key national High-Performance Computing (HPC), Artificial Intelligence (AI), and Science Infrastructure (SI) platforms, including:

- ACCESS-CI (Advanced Cyberinfrastructure Coordination Ecosystem: Services & Support)
- NAIRR (National Artificial Intelligence Research Resource Pilot)
- CloudBank
- NRP (National Research Platform)

**Written Reflection:** Following platform account setup or verification, students must upload a structured reflection paper to their Google Drive deliverable folder. The document must articulate how allocation on these national supercomputing assets supports their academic coursework or undergraduate research projects (e.g., accessing GPU clusters via NAIRR for machine learning model training or using ACCESS-CI allocations for distributed parallel processing).

## Hands-On AI Workshop: AI-Accelerated Portfolio Engineering & Workflow Continuity

During Session 2, lead instructor Jeaime Powell led a live technical demonstration detailing how developers leverage modern Large Language Models (LLMs) to streamline web development, portfolio construction, and context management across dynamic development environments.

### The AI to SI (Super Intelligence) Federal Mandate

During the workshop, Powell highlighted a key policy and terminological shift across federal research agencies. As of late September 2026, National Science Foundation directives began transitioning official terminology across research portals from Artificial Intelligence (AI) to Super Intelligence (SI).

SGX3 aligns its workforce development curriculum directly with these federal standards, integrating training on national infrastructure portals such as the NAIRR Pilot ([nairrpilot.org](https://nairrpilot.org)). This ensures participants understand how advanced multi-modal models and automated reasoning agents operate within federal research frameworks.

### Sustainable Compute & Cyberinfrastructure Literacy

The workshop addressed real-world high-performance computing challenges, focusing on data center energy consumption, cooling infrastructure, and environmental impact. Powell contrasted open-loop cooling systems with sustainable closed-loop architectures:

- **Open-Loop Systems:** Draw groundwater, circulate it once through computational clusters, and discharge thermal effluent. This approach accelerates pipe corrosion from mineral deposition and can contribute to local environmental degradation.
- **Closed-Loop Systems:** Recirculate treated water through sealed industrial loops. For example, the Texas Advanced Computing Center (TACC) operates a 2-million-gallon closed-loop thermal reservoir, preserving water assets and extending system hardware lifespans.

This technical context framed student discussions around data center siting, power consumption, and tribal land sovereignty, emphasizing that responsible HPC developers must consider environmental sustainability alongside computational performance.

### Real-World Industry Expectations & Token Metrics

Addressing cohort questions regarding AI usage in software development, Powell and student lead Abraham Ashade emphasized that top-tier technology employers (such as Amazon Web Services) actively encourage AI integration. Modern engineering teams track LLM token utilization during performance reviews to measure development efficiency.

Rather than replacing core computational literacy, prompt engineering and automated code generation are expected industry standards. Developers are required to understand underlying code structures while using AI tools to eliminate routine boilerplate development.

### Step-by-Step Technical Guide: AI Portfolio Engineering Workflow

| Step | Action | Result |
|---|---|---|
| 1. Model Selection & Prompting | Select an LLM (Claude, Z.ai GLM-5) | Generate semantic HTML5/CSS3/JS templates |
| 2. Context Optimization via PDF Ingestion | Ingest your LinkedIn PDF profile | Auto-populate resume, bio, & skill sets |
| 3. Deployment Configuration | Push to a GitHub repository | Enable GitHub Pages live deployment |
| 4. Session State Management | Log state in `pick_up_and_go.md` | Preserve context across models & environments |

#### Step 1: Model Selection & Prompt Engineering

Developers begin by selecting advanced LLMs optimized for code synthesis—such as Claude or Z.ai (GLM-5). Using structured prompt engineering, developers instruct the model to produce clean, modular, and responsive semantic HTML5, modern CSS3 layout rules, and vanilla JavaScript.

#### Step 2: Context Optimization via Document Ingestion

To eliminate manual data entry, developers export their LinkedIn profile as a PDF and feed the document directly into the LLM context window. The model parses work histories, education, project descriptions, and core technical competencies, automatically populating template structures with personal details.

#### Step 3: GitHub Pages Repository & Deployment Configuration

1. **Repository Setup:** Create a new public repository named `username.github.io` or a dedicated portfolio repository on GitHub.
2. **Code Commit:** Save the AI-generated `index.html`, stylesheet (`styles.css`), and asset files, committing them to the repository's `main` branch via the Git CLI or GitHub interface.
3. **Configure GitHub Pages:** Navigate to repository **Settings > Pages**. Under **Build and deployment**, set the branch to `main` and folder to `/ (root)`, then select **Save**.
4. **Verification:** Test the live URL generated by GitHub Pages to confirm that layout rendering, image paths, media queries, and hyperlinked social media profiles (LinkedIn, GitHub, ORCID) load correctly across desktop and mobile viewports.

#### Step 4: Managing Session State with `pick_up_and_go.md`

To prevent context loss across development sessions or when switching between AI platforms (e.g., moving between Claude, ChatGPT, and GLM-5), developers maintain a standard Markdown file in the project root titled `pick_up_and_go.md`.

This file acts as an external memory log for the project, tracking:

- Current project architecture and live deployment status.
- Active prompt histories and system instructions used.
- Core architectural and styling decisions made in previous sessions.
- Outstanding bugs, feature backlogs, and immediate next steps.

When opening a new development session, the developer uploads `pick_up_and_go.md` to the active AI model, instantly restoring full working context without manual re-prompting.
