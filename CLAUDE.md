# CLAUDE.md

At the start of every session, read `PICKUPANDGO.md` for project state,
rules, and open items. See `DEVELOPMENT.md` for build and deploy details.

Whenever you make a change to this project, update `PICKUPANDGO.md` in the
same piece of work: refresh "Last updated", "Current state", and
"Open items", and add a dated line to the "Change log".

Whenever a link is added anywhere on the site (session summaries, home
page, etc.), also add it to `_data/resources.yml` so it appears on the
Resources page.
